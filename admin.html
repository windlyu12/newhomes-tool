📥 Lead Capture (Google Sheets)

Khi khách xuất báo giá sẽ phải nhập SĐT. Dữ liệu leads được gửi về Google Sheets.

Tạo từ Google Apps Script. Xem hướng dẫn bên dưới.
📖 Hướng dẫn setup Google Sheets
  1. Tạo Google Sheet mới với các cột: Timestamp, Họ tên, SĐT, Căn hộ, Loại căn, Vật liệu, Tổng tiền, Loại xuất, Đồng ý tư vấn
  2. Vào Extensions → Apps Script
  3. Paste code sau vào: 
    function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.timestamp, data.name, data.phone, data.aptName,
    data.aptType, data.material, data.total, data.exportType,
    data.consent ? 'Có' : 'Không'
  ]);
  return ContentService.createTextOutput('OK');
}
  4. Deploy → New deployment → Web app
  5. Chọn "Anyone" can access → Deploy
  6. Copy URL và paste vào ô trên
